  1. Usa tu script de Python para consultar la API oficial de Meta Ads.
  2. Exporta las métricas actualizadas como un archivo data.json.
  3. Configura un GitHub Action gratuito que ejecute el script diariamente y actualice el repo.
# Script de actualización para MOTORIA Meta Ads Dashboard

    "leads_october": leads_mes_actual,
    "cpl": cpl_actual,
    "daily_series": df_daily.to_dict(orient="records")
}

    json.dump(metrics_data, f, indent=4)
